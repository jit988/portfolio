# Biprajit Kar — Creative Portfolio Website

A modern, responsive, and futuristic single-page portfolio website crafted for Biprajit Kar (Digital Journalist, Multimedia Creator, and Web Developer). Designed with a deep-dark theme, glassmorphism aesthetics, dynamic glowing accents, particle animations, and a mobile-friendly slide-out navigation menu.

✨ Features

Futuristic Dark Aesthetic: Deep dark slate palette (#080a12) paired with violet (#a78bfa) and cyan (#67e8f9) visual accents.

Floating Transparent Navigation: Glassmorphism floating header with a live top-scroll progress indicator.

Animated Mobile Navigation: Hamburger-to-X menu button with a full-screen blurred glass drawer overlay for mobile screens.

Interactive Particle Background: Lightweight HTML5 Canvas particle system that smoothly adapts to viewport resizing.

Interactive Intro & Preloader: Animated initialization screen leading into a full-screen welcoming entry overlay.

Dynamic Content Sections:

Hero Section: Showcase with floating status cards and quick action buttons.

Visual Inspiration Gallery: Interactive tile grid showcasing core domains.

About & Profile: Detailed biography, key highlights, and primary photograph (images/biprajit.GIF).

Skills & Toolkit: Modern skill cards categorized by specialty.

Featured Work: Direct target links pointing to functional project categories:

Campaign (#social-campaign)

Documentary (#documentary)

Web Design (#web-design)

AI Concept (#ai-concept)

Contact Area: Call-to-action card with email quick-link integration (mailto:).

Smooth Animations & Performance: Intersection Observer scroll reveals, scroll-to-top floating button, and automatic system motion preference compliance (prefers-reduced-motion).
